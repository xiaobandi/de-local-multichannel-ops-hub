# 多平台连接 · 架构与流程图

## 本技能的四层结构

```mermaid
flowchart TB
  U["使用层：多平台运营中台 的使用者"]
  T["触发层：多平台连接"]
  X["执行层：5 个步骤"]
  O["产出层：统一数据流"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 已同时运营美团+抖音+小红书的进阶门店（能同步多平台的商家不足三成，据 R4 调研）；员工定位：一次编辑，三平台同步的跨平台传送带 |
| 触发层 | 关键词 / 显式点名「多平台连接」；触发方式：用户提出需求 |
| 执行层 | **接收输入**：确认拿到的是「多平台授权」，先做完整性检查。 → **美团/抖音/小红书数据读取（BusinessConnector）**：按该定义执行，并把用到的输入项显式写进产出。 → **交叉校验**：把本步结论与上一步结论对一遍，出现矛盾先解决矛盾再往下走。 → **落盘产出**：按「输出契约」四要素定稿，缺数据的写 `<待填>`。 → **回指自检**：逐个数字回指输入来源，回指不上的删掉。 |
| 产出层 | 统一数据流 |
