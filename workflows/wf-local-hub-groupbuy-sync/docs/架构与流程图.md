# 团购信息多平台同步 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：多平台运营中台 的使用者"]
  T["触发层：团购信息多平台同步"]
  X["执行层：2 个步骤"]
  O["产出层：各平台上架信息核对清单"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 已同时运营美团+抖音+小红书的进阶门店（能同步多平台的商家不足三成，据 R4 调研）；员工定位：一次编辑，三平台同步的跨平台传送带 |
| 触发层 | 关键词 / 显式点名「团购信息多平台同步」；触发方式：人工触发+定时校验 |
| 执行层 | 套餐变更 → 各平台上架信息核对清单 |
| 产出层 | 各平台上架信息核对清单 |
